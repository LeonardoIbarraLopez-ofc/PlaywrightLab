# Prompts del laboratorio

## Prompt 1 — Explorar
Analiza la aplicación local en http://127.0.0.1:3000 utilizando Playwright. Identifica las funcionalidades disponibles y los elementos que deberían probarse.

## Prompt 2 — Generar pruebas
Analiza la aplicación y crea una suite Playwright en TypeScript para:
- carga inicial
- creación de tarea
- completar tarea
- eliminar tarea
- validación de tarea vacía

Guarda las pruebas en la carpeta tests.

## Prompt 3 — Revisar
Revisa las pruebas existentes de Playwright. Evalúa locators, assertions, estabilidad, duplicación y mantenibilidad. No cambies nada todavía; primero explica tus hallazgos.

## Prompt 4 — Corregir
Corrige los problemas encontrados y ejecuta nuevamente las pruebas.

## Prompt 5 — Investigar un fallo
Ejecuta la suite. Si alguna prueba falla, reproduce el problema, identifica la causa, explica la solución, modifica el código y vuelve a ejecutar las pruebas.

## Prompt 6 — Desafío
Agrega una nueva funcionalidad de prueba sin modificar la aplicación: crear cinco tareas, completar dos, eliminar una y verificar el resumen final.
